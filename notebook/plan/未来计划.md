# 未来计划

## 近期

### 短链接高级功能
- 支持自定义短码（用户指定短码）
- 支持短链接密码访问
- 支持短链接过期时间设置
- 支持短链接访问次数限制

### 统计增强
- 实时统计仪表盘（WebSocket 推送）
- 统计数据导出（CSV/Excel）
- 访问趋势图表优化
- 地区热力图

### 前端优化
- 移动端适配优化
- 批量操作优化（批量删除、批量恢复）
- 短链接搜索和筛选增强

## 中期

### 高可用
- Redis Sentinel / Cluster 支持
- MySQL 主从复制
- 应用多实例部署 + 负载均衡
- 健康检查和自动故障转移

### 性能优化
- 热点短链接预热缓存
- 统计数据写入优化（批量写入）
- Bloom Filter 动态扩容
- 号段预分配策略优化

### 安全增强
- 短链接域名白名单管理
- 恶意链接检测（钓鱼、诈骗）
- 访问频率异常告警
- API Token 权限细分

## 长期

### 多租户
- 基于团队的短链接隔离
- 配额管理和计费
- 团队成员权限管理

### 开放平台
- 开放 API 文档和 SDK
- Webhook 回调通知
- 第三方集成（企业微信、钉钉、飞书）

### 智能化（已实现）
- ✅ AI 运营助手（AI Copilot）：基于 AgentScope ReAct Agent，6 个分析工具，SSE 流式交互
- ✅ 多轮对话上下文：会话/消息持久化到 MySQL，支持历史会话管理
- ✅ 流量异常检测：PV 骤降、UV 飙升、零流量僵尸链接自动识别
- ✅ 链接健康检查：过期链接、禁用链接、僵尸链接一键诊断
- 智能短码推荐
- 访问模式分析和预测
