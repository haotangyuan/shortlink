## 修复内容

1. **AI 未配置导致启动失败**：控制器改为按需获取 `ReActAgent`，缺少 API Key 时返回明确的 SSE 降级消息，不阻塞应用启动。
2. **创建结果无法直接用于编辑**：更新短链前统一去除 `http://` 或 `https://`，兼容创建接口返回的完整 URL 与数据库中的裸地址。
3. **当日统计汇总为零**：查询结束日期补齐到当天 `23:59:59`，同时允许“今日 PV”聚合无记录时返回 `0`。
4. **Token 操作命中错误记录**：Snowflake ID 按字符串序列化，避免超过 JavaScript 安全整数范围后发生精度丢失。
5. **仪表板正常查询触发 429**：用户级 Redis + Lua 风控仅统计已登录用户的写请求，读请求与公开请求不再占用写入额度。
6. **脱敏手机号被再次持久化**：前后端均忽略包含 `*` 的手机号，保存资料时不会用掩码覆盖真实密文。
7. **空分组链接数为空**：无聚合结果时统一返回 `0`，避免页面出现空白计数。
8. **列表短链无法正确打开**：展示、复制和外链统一补全 `http://`，接口查询参数仍保留服务端要求的裸地址。
9. **回收站删除时间为空**：链接进入回收站时记录 `delTime`，页面可展示真实操作时间。
10. **访问来源分类不准确**：缺失 `User-Agent` 时安全返回 `Unknown`；Android、iOS 和 Opera 在桌面兼容标记之前识别，避免移动端被统计为 Unix/Mac、Opera 被统计为 Chrome。
11. **前端加载与可访问性告警**：补充懒加载占位、图表初始尺寸、favicon、表单自动填充属性和图标按钮名称，真实浏览器控制台无 error/warning。
