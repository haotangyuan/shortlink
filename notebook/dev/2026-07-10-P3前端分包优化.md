# P3 前端分包优化

## 背景

生产构建的所有业务页面均由路由入口同步导入，导致 Recharts、React Markdown 等仅在特定页面使用的依赖进入主 JavaScript 分块。优化前主分块为 931.37 kB，超过 Vite 的 500 kB 提示阈值。

## 方案

- 保留公共布局、鉴权守卫和全局 Provider 同步加载。
- 使用 React Router 的 `lazy` 路由按页面动态导入业务模块。
- 将统计图表与 AI Markdown 渲染依赖分别隔离到 Analytics 和 AI 页面分块。
- 增加浏览器路由测试，验证动态导入后的登录页面能够正常渲染。

## 结果

- 主 JavaScript 分块由 931.37 kB 降至 357.07 kB，减少 61.7%。
- Analytics 页面分块为 365.85 kB，AI 页面分块为 165.95 kB。
- 生产构建不再出现单分块超过 500 kB 的警告。
- 用户首次访问只加载当前路由所需页面代码，其他页面在导航时按需获取。

## 测试

- `npm test`：全量通过。
- `npm run typecheck`：通过。
- `npm run build`：通过，无大分块警告。
- `git diff --check`：通过。
