# P1 问题修复

## 背景

剩余模块审查发现三项高优先级问题：AI 会话可被其他用户使用相同会话标识污染、IP 地理服务失败响应会导致统计消费空指针、登出后旧会话 token 会在再次登录时被重新激活。

## 方案

- AI 会话创建发现同名会话时校验用户名，不属于当前用户则按会话不存在处理。
- 高德 IP 查询返回失败状态时提供 Unknown 地理信息，保持 IpGeoClient 的非空结果约定。
- 登出同时删除会话映射和用户 token 索引，并停止在异常日志中输出 token。
- 为三个问题分别增加回归测试，测试均在修复前失败、修复后通过。

## 影响范围

- 不修改 API 路径、请求响应结构、数据库表结构或 Redis key 格式。
- 已有用户自己的 AI 会话仍复用原记录，其他用户无法写入该会话。
- 高德服务的业务失败响应不再阻断统计消息消费。
- 登出后的 token 不会被后续登录流程复用。

## 测试

- mvn test：11 项测试通过。
- npm test：2 个测试文件、3 项测试通过。
- npm run build：TypeScript 编译与 Vite 生产构建通过；保留现有的大分块提示。
- git diff --check：通过。

## 遗留问题

AI 提问仍通过 GET 查询参数发送，API Token 创建仍存在数据库与 Redis 双写一致性风险，前端链接搜索和统计访问记录分页仍需后续处理。
