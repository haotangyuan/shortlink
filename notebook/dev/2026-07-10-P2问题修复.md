# P2 问题修复

## 背景

模块审查继续发现四项中优先级问题：AI 提问通过 URL 查询参数传输、API Token 的数据库与 Redis 状态可能不一致、链接搜索只过滤当前页、访问记录接口虽已分页但前端无法翻页。

## 方案

- AI 流式接口改为 POST JSON 请求，日志只记录消息长度，并拒绝空消息。
- Token 创建、启用、禁用和删除增加数据库事务；吊销时先删除 Redis 鉴权映射，失败则不更新数据库状态，避免界面显示已吊销但令牌仍可用。
- 链接分页请求增加关键词，MyBatis 在短链接、原始链接和描述字段上执行服务端模糊搜索。
- 访问记录页码进入 React Query 缓存键，切换筛选条件时重置页码，并提供上一页、下一页操作。
- 为 AI 请求方式、Token 吊销失败、搜索参数和访问记录翻页增加回归测试。

## 影响范围

- AI 流式接口请求方法由 GET 调整为 POST，请求体为 `message` 和 `sessionId`。
- 不修改数据库表结构、Redis key 格式或分页响应结构。
- 链接搜索结果覆盖整个分组，不再局限于当前已加载页面。
- Token 吊销依赖 Redis 可用；Redis 异常时明确返回失败，保持鉴权状态与管理状态一致。

## 测试

- `npm test`：全量通过。
- `npm run build`：TypeScript 编译与 Vite 生产构建通过；保留现有的大分块提示。
- `git diff --check`：通过。
