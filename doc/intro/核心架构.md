# 核心架构

## 总览

ShortLink 是一个高性能短链接服务，采用 Spring Boot 3 后端 + React 前端的分层架构。

```
前端 (React/Vite) ──HTTP──▶ REST Controller ──▶ Service ──▶ DAO
                                                      │
                                          ┌───────────┼───────────┐
                                          ▼           ▼           ▼
                                      Cache       MQ          Database
                                   (Caffeine    (Redis     (MySQL +
                                    + Redis)    Stream)   ShardingSphere)
```

## 核心流程

### 短链接创建

```
POST /api/short-link/v1/create
  → LinkServiceImpl.createShortLink()
    → 号段分配：Redis INCRBY 批量取号（10000 个/批）
    → 仿射变换：y = (a * i + b) mod 62^6
    → Base62 编码：6 位短码
    → 写入 DB（分片表 t_link_N）
    → 回填缓存（Caffeine + Redis）
    → 更新 Bloom Filter
```

### 短链接跳转

```
GET /{短码}
  → LinkServiceImpl.restoreUrl()
    → L1 Caffeine 命中？→ 返回
    → L2 Redis 命中？→ 回填 Caffeine → 返回
    → L3 Bloom Filter 不存在？→ 返回 404
    → L4 空值缓存存在？→ 返回 404
    → 本地锁 + 双重检查
    → 查询 DB（分片表）
    → 记录存在：回填缓存 → 302 重定向
    → 记录不存在：写入空值缓存 → 404
    → XADD 统计消息到 Redis Stream
```

### 访问统计消费

```
Redis Stream (stats)
  → StatsConsumer (Consumer Group)
    → 幂等检查（messageId 唯一索引 + Redis 标记）
    → Lua 脚本：PFADD HyperLogLog + 计算 UV/UIP 增量
    → 查询 IP 地理位置（ip2region）
    → 写入访问日志表
    → 更新统计数据（PV/UV/UIP/地区/设备/浏览器/网络）
    → XACK 确认
```

## 关键类职责

## 数据分片

ShardingSphere 按 `gid` 哈希分 16 张表：

```
t_link_0, t_link_1, ... t_link_15     ← 短链接表
t_group_0, t_group_1, ... t_group_15  ← 分组表
t_goto_0, t_goto_1, ... t_goto_15    ← 跳转统计表
```

配置文件：`src/main/resources/shardingsphere-config.yaml`

## 多级缓存

```
请求 → L1 Caffeine (10min, 本地热点)
         ↓ miss
       L2 Redis (分布式缓存)
         ↓ miss
       L3 Bloom Filter (快速否定)
         ↓ may exist
       L4 空值缓存 (30min, 防穿透)
         ↓ not cached
       本地锁 + 双重检查 → 查询 DB → 回填缓存
```

## 认证体系

- **Admin 接口** (`/api/short-link/admin/v1/*`)：登录后返回 Session Token，放在 `Authorization: Bearer <token>`
- **Core 接口** (`/api/short-link/v1/*`)：使用 API Token（后台管理页面创建）
- **短链跳转** (`/{短码}`)：无需认证
